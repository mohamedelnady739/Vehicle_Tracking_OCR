# 🚗 Vehicle Tracking & Egyptian License Plate OCR

An AI-powered Computer Vision project for vehicle detection, tracking, and Egyptian license plate recognition using Deep Learning.

## 🎯 Project Overview

This project aims to build a system that processes images and videos to detect vehicles, track them across video frames, detect Egyptian license plates, and recognize plate text using OCR.

## ✨ Key Features

- **Vehicle Detection:** Detect cars, motorcycles, buses, and trucks using YOLO.
- **Multi-Object Tracking:** Track detected vehicles across video frames using ByteTrack.
- **License Plate Detection:** Detect Egyptian license plates using a custom-trained YOLO model.
- **Optical Character Recognition (OCR):** Extract text from detected license plates using EasyOCR.
- **Interactive Web Application:** Upload images and videos and visualize the detection and tracking results using Streamlit.
- **Data Export:** Export available recognition results to CSV for further analysis.

## 🛠️ Technologies Used

- Python
- YOLO
- ByteTrack
- OpenCV
- EasyOCR
- Streamlit
- NumPy
- CSV

## 🧠 Computer Vision Pipeline

1. Input image or video.
2. Vehicle detection.
3. Vehicle tracking and ID assignment.
4. License plate detection.
5. Plate text recognition using OCR.
6. Visualization and CSV export.

## 🚀 Project Goal

The goal is to combine object detection, multi-object tracking, and OCR into a practical Computer Vision application for intelligent traffic monitoring.
